# Provenance Requirements

Every important source should eventually record:

- dataset_id
- title
- provider
- source URL
- source publication/version date
- source year
- download timestamp
- original filename
- file size
- SHA-256
- license / usage notes
- spatial coverage
- temporal coverage
- CRS where applicable
- processing lineage
- reliability / provenance category
- calibration vs held-out exposure status where relevant

Prefer machine-readable provenance plus human-readable notes.
